## Fitur tambahan kelas

- QR dibuat lokal dan tombol salin tautan sesi.
- Pemilihan domain, preview paket beku dan template lokal yang dapat digunakan kembali.
- Pembahasan mengikuti nomor host setelah kunci dibuka; peserta dapat memilih navigasi mandiri.
- Ringkasan domain dan soal paling banyak salah untuk menentukan prioritas pembahasan.
- Latihan pribadi dari kesalahan kelas tanpa akun; jawaban kelas tetap terpisah.
- Rencana, catatan, laporan dan cadangan dibagi menjadi empat bagian agar halaman belajar lebih mudah dipindai.

## Database dan pengoperasian

Migrasi `supabase/migrations/20261019_classroom_upgrade.sql` mandiri dan dapat dijalankan ulang. Tidak menghapus sesi/jawaban lama. Pengguna telah menjalankannya di Supabase; pemeriksaan langsung mengonfirmasi `classroom_rpc` versi 2 dan `report_rpc` siap.

Host memilih kebijakan peserta terlambat sebelum/saat ujian; peserta baru tetap menggunakan nama dan kode sesi. Pemulihan perangkat dilakukan host melalui Monitor; berikan kode sementara hanya kepada peserta terkait. Untuk mengganti perangkat instruktur, buat kode pindah host lalu gunakan formulir pemulihan sebagai host pada perangkat baru. Kode tidak dimasukkan ke URL, dan akses lama dicabut saat kode dipakai.

Daftar laporan pengelola memerlukan akun Supabase dengan role admin tepercaya. Tidak ada role yang dapat dinaikkan sendiri dari profil peserta. Endpoint laporan bukan penyunting bank; layanan penyunting/publikasi bank tetap menggunakan backend editorial yang sudah ada.
