# Bahasa tampilan — 13 Oktober 2026

Pemilih Bahasa Indonesia/English tersedia sebelum login, pada header utama, dan saat ujian. Bahasa Indonesia menjadi default. Pilihan tersimpan pada browser dan ikut diperbarui pada tab lain.

Bahasa tampilan mengubah menu, petunjuk, tombol, status, hasil, riwayat, formulir admin/kelas, judul dokumen, dan format tanggal. Bahasa soal dipilih secara terpisah di ruang belajar. Pertanyaan, opsi, dan pembahasan mempertahankan bahasa bank yang dipilih; atribut `lang` pada konten membantu pembaca layar mengenali bahasa tersebut. PDF memakai bahasa antarmuka yang sedang ditampilkan.

Pergantian bahasa ketika ujian aktif mempertahankan ID sesi, pertanyaan, jawaban, penanda, posisi, konfigurasi, dan deadline timer. Tidak memerlukan migrasi database atau panggilan penerjemahan AI.

Implementasi menggunakan context React dan katalog lokal di `src/i18n/`. Preferensi tersimpan pada `aws-exam-ui-language`; nilai tidak valid kembali ke Indonesia, dan pemilih masih berfungsi dalam memori jika storage preferensi diblokir. Label kontrol diterjemahkan dan dapat diakses lewat keyboard.

Validasi lokal: build/lint lulus; 28 tes unit/API/RLS lulus. Tiga belas skenario browser regresi dan enam pemeriksaan bahasa lulus. Pemeriksaan baru mencakup reload, lintas tab, sesi/timer tetap sama, layout 360/390/768 px, hasil/riwayat bilingual, serta soal English dengan tampilan Indonesia. Artefak berada di `artifacts/language/` (ignored).

Jalankan `node tests/language-browser.mjs` setelah build untuk pemeriksaan lokal. Untuk smoke test website tanpa membuat akun atau menulis cloud history, set `EXAM_TEST_URL` ke URL deployment HTTPS sebelum menjalankan skrip yang sama.

Referensi implementasi: [React context](https://react.dev/reference/react/useContext) dan [atribut bahasa HTML](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes/lang).
